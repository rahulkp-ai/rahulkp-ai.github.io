# Rahul KP — Portfolio (2026 Edition)

Modern, dark-themed, responsive portfolio built with **HTML5, CSS3, Bootstrap 5, and vanilla JS**.

## Features

- Animated gradient background with floating orbs
- Glassmorphism cards across all sections
- Smooth AOS scroll animations
- Fully responsive (mobile / tablet / desktop)
- 40+ verified Coursera certifications with live verify links
- Local assets (images + resume PDF)

## Run locally

Just open `index.html` in a browser, or serve with:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

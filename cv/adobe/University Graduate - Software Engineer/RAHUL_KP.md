### Neural Collaborative Filtering Recommendation System

**Python · NumPy · PyTorch · FastAPI · PostgreSQL · Next.js · Docker · Kubernetes**

- Designed and implemented a complete **Neural Collaborative Filtering (NCF)** recommendation system covering mathematical formulation, model implementation, evaluation, API serving, frontend integration, and production architecture.
- Implemented the core recommendation models **from scratch using NumPy**, including Generalized Matrix Factorization (GMF) and Multi-Layer Perceptron (MLP), before reproducing the models using PyTorch.
- Built a reproducible MovieLens 1M evaluation pipeline using **1:4 negative sampling** and leave-one-out evaluation with 99 negative candidates.
- Evaluated recommendation quality using **Hit@10 and NDCG@10**, achieving approximately **0.628 Hit@10** and demonstrating comparable recommendation quality between the scratch and PyTorch implementations.
- Benchmarked the implementations and measured approximately **12.8× epoch-level training speedup with PyTorch** over the NumPy implementation.
- Built a production-oriented architecture using **FastAPI model serving, PostgreSQL, Next.js, Docker, Nginx, Kubernetes, monitoring, and infrastructure-as-code concepts**.
- Implemented approximately **1.23M trainable parameters** and documented model architecture, training methodology, evaluation methodology, benchmarking, and deployment design.
- Authored a research preprint documenting the implementation, empirical evaluation, and production architecture.

**Engineering focus:** algorithms, numerical computing, benchmarking, APIs, database integration, deployment, reproducibility, performance.
